# 🏥 Healthcare EDA Dashboard | Power BI

An interactive **Healthcare Exploratory Data Analysis (EDA) Dashboard** built using **Microsoft Power BI** to analyze patient demographics, medical conditions, billing, admissions, clinical information, and healthcare trends.

---

## 📊 Project Overview

The **Healthcare EDA Dashboard** converts healthcare data into an interactive visual analytics solution.

The dashboard allows users to explore different aspects of patient and healthcare data through interactive charts, KPIs, slicers, and filters.

The primary objective of this project is to understand:

* Patient demographics
* Medical conditions
* Admission patterns
* Billing amounts
* Insurance providers
* Length of stay
* Medication usage
* Test results
* Gender and age-group distribution
* Healthcare trends over time

---

## 🎯 Objectives

The main objectives of this project are:

* Perform exploratory data analysis on healthcare data.
* Create meaningful healthcare KPIs.
* Analyze patient demographics.
* Understand admission patterns.
* Analyze billing amounts across different categories.
* Explore medical conditions and clinical information.
* Identify trends across years and months.
* Build an interactive and user-friendly Power BI dashboard.
* Present complex healthcare data through effective data visualization.

## 📑 Dashboard Pages

### 1. Overview

The Overview page provides a high-level summary of the healthcare dataset.

**Key metrics and analysis include:**

* Total Patients
* Average Age
* Total Billing Amount
* Length of Stay
* Gender Distribution
* Medical Condition Distribution
* Admission Type
* Test Results
* Interactive filters

---

### 2. Demographics

The Demographics page focuses on understanding the characteristics of the patient population.

**Analysis includes:**

* Gender Distribution
* Age Group Distribution
* Blood Type Distribution
* Medical Condition by Age Group
* Admission Type
* Insurance Provider
* Interactive demographic filtering

---

### 3. Billing

The Billing page analyzes healthcare billing patterns.

**Analysis includes:**

* Billing Amount by Medical Condition
* Billing Amount by Gender
* Billing Amount by Insurance Provider
* Billing Amount by Admission Type
* Year-wise Billing Trends
* Interactive filters for detailed analysis

---

### 4. Trends

The Trends page focuses on changes in healthcare data over time.

**Analysis includes:**

* Year-wise Billing Trends
* Year-wise Patient Trends
* Monthly Patient Trends
* Admission Type distribution
* Medical Condition trends
* Interactive year and category filters

---

### 5. Clinical

The Clinical page focuses on medical and clinical information.

**Analysis includes:**

* Length of Stay by Medical Condition
* Medication by Medical Condition
* Test Results by Medical Condition
* Admission Type by Medical Condition
* Clinical-level filtering and comparison
